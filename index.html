SMART SCHOOL MODULES

Flip a card to reveal its wiring architecture • Click DETAILS for the full system breakdown

01

AUTOMATIC SCHOOL GATE

IR SENSOR + SERVO MOTOR

Detects a person at the entrance, counts the object and opens the gate in automatic mode.

01 / WIRING ARCHITECTURE
IR OUT D7→ARDUINO UNO→SERVO SIGNAL D9
SERVO VCC→5V / EXT. SUPPLY
SERVO GND→COMMON GND
Sensor output goes to D7. The servo signal uses D9; power the servo from an appropriate supply and share ground with Arduino.
02

SMART CLASSROOM LIGHT

IR SENSOR + LED

Turns the classroom light output on/off through the Arduino-controlled driver stage.

02 / WIRING ARCHITECTURE
IR SENSOR→ARDUINO D7
ARDUINO D3→MOSFET / DRIVER→LED LOAD
LOAD SUPPLY −→ARDUINO GND
D3 is the control output. Do not power a large LED load directly from an Arduino pin; use the driver stage already used in your project.
03

OBJECT COUNTER

IR SENSOR + ARDUINO

Counts each new IR detection and sends COUNT:n over the USB serial connection to the dashboard.

03 / WIRING ARCHITECTURE
IR VCC→5V
IR GND→GND
IR OUT→D7→COUNT:n → USB
The sketch counts the LOW-to-detected edge, so one object is counted once until the sensor is clear again.
04

AUTOMATIC SCHOOL BELL

ARDUINO + DC MOTOR

The school bell can be started from the dashboard and stopped from the same control. Timer UI is handled by the website.

04 / WIRING ARCHITECTURE
ARDUINO→DRIVER / TRANSISTOR→DC MOTOR
MOTOR +→SEPARATE SUPPLY +
SUPPLY −→COMMON GND
Use a suitable motor driver/transistor and separate motor supply. The Arduino output is a control signal, not the motor power source.
05

RAIN DETECTION SYSTEM

RAIN SENSOR + ARDUINO

Detects rain and can be expanded with an alert or automated response module.

05 / WIRING ARCHITECTURE
RAIN VCC→5V
RAIN GND→GND
RAIN OUT→ARDUINO INPUT
This is shown as a project architecture card; the current final sketch does not assign a rain-sensor pin.
06

CLASSROOM FANS

FAN 1 D5 + FAN 2 D10

Two classroom fans are independently controlled from the website through MOSFET/driver stages.

06 / WIRING ARCHITECTURE
ARDUINO D5→MOSFET 1 G→FAN 1
ARDUINO D10→MOSFET 2 G→FAN 2
BATTERY −→SOURCE 1 + SOURCE 2 + GND
Fan power must come from the appropriate external supply through the driver stage. D5 and D10 only control the MOSFET gates.
07

FIRE SAFETY SYSTEM

FLAME SENSOR + BUZZER

The dashboard can trigger a rapid beep pattern; the current Arduino buzzer output is D6.

07 / WIRING ARCHITECTURE
FLAME SENSOR→ARDUINO INPUT
ARDUINO D6→BUZZER
BUZZER −→GND
The website rapidly alternates B/b commands for the test alarm. Press STOP to end the pattern.
08

SOLAR ENERGY SYSTEM

SOLAR PANEL + POWER

Demonstrates solar generation and how a separate power stage can support the model.

08 / WIRING ARCHITECTURE
SOLAR PANEL +→CHARGE / POWER STAGE
SOLAR PANEL −→POWER STAGE −
POWER STAGE→PROJECT LOADS
Use the appropriate charge-control and power-management hardware for the panel/battery setup; keep high-current loads separate from Arduino I/O.
